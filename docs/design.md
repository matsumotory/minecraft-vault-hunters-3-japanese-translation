# デザインの決め (ロゴと公開物の色彩)

一般的な紺+金の既製配色を使わず、Vault Huntersのテーマの実測色だけから定義する。出典は2つ。公式サイトvaulthunters.ggの計算済みスタイルの実測 (2026-08-14) と、同梱の訳文データにあるゲーム内文字列の色タグの頻度の集計。

| 役割 | 色 | 出典 |
|---|---|---|
| 基調ダーク (第一背景) | #2F0B04 焦げ茶 | 公式サイトのダーク基調 (実測で最多の有彩背景) |
| 基調ダーク (第二背景) | #192022 暗スレート | ゲーム内色タグの頻出色 |
| 主アクセント | #FF9500 焔オレンジ | 公式サイトの主アクセント。ゲーム内#FF8900と同族 |
| 副アクセント | #FFBA00 琥珀 | ゲーム内色タグ。金の代わりにこの琥珀を使う |
| 主文字色 | #FCF5C5 羊皮紙 | ゲーム内色タグ |
| 冷アクセント (微量) | #A3E2F5 結晶シアン | ゲーム内色タグ (ヴォールトクリスタル系) |
| 使用注意 | #A64141 赤 | ゲーム内色タグでは最多だが意味が警告。装飾に使わない |

使い方の決め: 暗基調は焦げ茶か暗スレート (紺を使わない)。アクセントは琥珀から焔オレンジへのグラデーションを主役にし、結晶シアンは微量の差し色に限る。ゲーム画像・公式アートは流用せず、図形と文字だけの自作に保つ。

ロゴは羊皮紙基調のC案を採用している (明るい一覧面で目立つ反転デザイン)。生成はscripts/make_logo.pyで再現でき、コミット済みのsrc/main/resources/logo.pngとバイト単位で同一の出力になることを確認済み。CurseForgeのモデレーションからロゴ内の文字が指摘された場合は、文字なし版 (ダイヤと「日」だけ) へ差し替えて再提出する。
